# tools/post_sch: recorded edits to the master

These scripts are the record of each edit: text-level edits to `pi_power_board.kicad_sch`. **Run only a new script, or one marked re-runnable.** Every other script is history: re-run on today's master it stops at its guard at best, and at worst undoes later hand edits.

Each script: docstring = what, why, SPEC section; copies the master to `pi_power_board-backups/` with a timestamp first (no git); stops on any unexpected state; leaves every other item untouched; idempotent; every KiCad call under `timeout`.

State legend: **re-runnable** (safe to run again) · **applied-once** (record; stops at its guard) · **refuses** (blocks itself on the current master) · **historical** (kept for reference only).
