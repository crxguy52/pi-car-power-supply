# tools/post_route: recorded edits to the master

These scripts are the record of each edit: pcbnew edits to `pi_power_board.kicad_pcb` (KiCad python, saved next to the `.kicad_pro`). **Run only a new script, or one marked re-runnable.** Every other script is history: re-run on today's master it stops at its guard at best, and at worst undoes later hand edits.

Each script: docstring = what, why, SPEC section; copies the master to `pi_power_board-backups/` with a timestamp first (no git); stops on any unexpected state; leaves every other item untouched; idempotent; every KiCad call under `timeout`.

State legend: **re-runnable** (safe to run again) · **applied-once** (record; stops at its guard) · **refuses** (blocks itself on the current master) · **historical** (kept for reference only).

Guard for every script here: `tools/check_fixed.py` (KiCad python) verifies Edge.Cuts, MH1–MH4, J1/J2/J4/J5 (position, orientation, side, absolute pad coordinates, 1 µm) and the lead's drawings / rule areas against `tools/fixed_baseline.json` (generated once on 2026-11-04 from the lead's board; the generator refuses to overwrite it). The only other way it changes is a recorded lead decision, `--accept-lead-change <refs>` (guarded: every other item must pass and the change must be exactly the recorded one; the JSON keeps a `lead_changes` record): used 2026-11-05 for `J1,J4,J5` (180 deg turn about the pad rows) and `J2,J5` (the lead's layout copy: pure translations by recorded vectors) and `EDGE_RIGHT_NOTCH` (13: only the right edge line replaced by the recorded notch path) and `EDGE_RIGHT_NOTCH_UNDER_USB` (14: only the notch's five top items replaced). `--selftest` mutates each item (48 mutations; the rule-area mutations only touch the lead's rule areas, so a later keep-out such as 16's `AGND_KEEPOUT` is allowed).

Related: `tools/render_assembly.py` (KiCad python, read-only): `reports/assembly_top.png`, the top-side assembly drawing at 4:1 and 200 dpi (reference + value in each courtyard, pad 1 marked) for hand soldering, since most references don't fit on the silkscreen.
